# InterVUZ

1. Навигация по вузу
   Приложение помогает быстро находить нужные аудитории, кафедры, столовые, деканат, принтеры и другие важные точки в вузе. Пользователь может выбрать нужное место и получить понятный маршрут по корпусу. Это упрощает ориентацию для студентов, особенно для первокурсников и новых сотрудников.

2. Импорт расписания
   Пользователь может загружать или синхронизировать свое расписание в приложении, чтобы видеть все пары в одном месте. Приложение показывает время занятий, аудитории и помогает быстро перейти к нужной локации. Это экономит время и делает учебный процесс удобнее.

3. Букинг аудиторий
   Старосты, преподаватели и сотрудники смогут смотреть свободные аудитории и бронировать их для занятий, встреч или мероприятий. Система поможет избежать пересечений и упростит поиск доступных помещений. Это особенно полезно при замене кабинетов или организации внеучебных активностей.

4. ИИ-ассистент
   Встроенный ассистент отвечает на повседневные вопросы студентов: где поесть, где распечатать документы, как найти нужный кабинет или сервис. Он быстро подсказывает полезную информацию внутри вуза и помогает ориентироваться в кампусной жизни. Это делает приложение не просто справочником, а персональным помощником студента.
